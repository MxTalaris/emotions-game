# Memory Bank — Emotions Game

Contexto persistente do projeto para sessões futuras com AI.

## Arquivos

| Arquivo | Conteúdo |
|---------|----------|
| [projectbrief.md](./projectbrief.md) | Objetivo, escopo do MVP, mecânicas |
| [productContext.md](./productContext.md) | Entidades, atributos, catálogo inicial |
| [systemPatterns.md](./systemPatterns.md) | Arquitetura, padrões, fluxo de dados |
| [techContext.md](./techContext.md) | Stack, comandos, configuração |
| [activeContext.md](./activeContext.md) | Estado atual e próximos passos |
| [progress.md](./progress.md) | Checklist do que foi feito e pendente |

## Uso

Ao iniciar uma nova sessão, leia estes arquivos para recuperar o contexto do projeto antes de implementar novas features.

Atualize `activeContext.md` e `progress.md` ao final de cada sessão significativa.
